<rules_of_engagement>
NON-NEGOTIABLE constraints from CONVENTIONS.md, CONTEXT.md decisions, and RESEARCH pitfalls:

1. **No try/catch, no exceptions.** Use `nlohmann::json::parse(content, nullptr, /*allow_exceptions=*/false)` and `.is_discarded()` for parsing. Use `std::error_code` overloads for ALL filesystem ops (`fs::rename(src, dst, ec)`, `fs::remove(p, ec)`, `fs::exists(p, ec)`, `fs::create_directories(p, ec)`, `fs::directory_iterator(p, ec)`).
2. **Never call `.at()` on a `nlohmann::json` value.** It throws even under `allow_exceptions=false` (Pitfall R-2). Use `obj.find(key) != obj.end() && it->is_*()` guards exclusively.
3. **Never call `j.value(key, default)` without an explicit `is_*()` type-check first.** It throws `json::type_error` on type mismatch (Pitfall R-1). The Recipe 2 helpers (`readInt`/`readFloat`/`readBool`/`readString`/`readWString`) implement the safe pattern; use them.
4. **Never use `std::wstring_convert<std::codecvt_utf8<wchar_t>>`.** It's deprecated in C++17. Use `WideCharToMultiByte(CP_UTF8, ...)` and `MultiByteToWideChar(CP_UTF8, MB_ERR_INVALID_CHARS, ...)` per Recipe 4.
5. **Never write directly to the destination path.** A crash mid-write corrupts the only saved config. Always temp-write + atomic swap via `writeAtomicWindows` (Recipe 9). Non-Windows branch keeps the existing direct-write fallback.
6. **All new file-local helpers go inside the EXISTING anonymous namespace** (line 23 open, line 112 close in the current file). Do NOT open a second anonymous namespace. Do NOT promote helpers to `src/common/`.
7. **Logger calls pass multiple args (variadic fold).** No `+` concatenation, no `<<`, no `\n` suffix (logger emits `std::endl` itself, verified at `src/common/src/logger.cpp:51`).
8. **`IConfigManager` header is stable** — do NOT touch `src/core/include/micmap/core/config_manager.hpp`. Do NOT add new virtual methods. Do NOT change `ConfigManagerImpl`'s ctor, dtor, or private members (`config_`, `configDir_`).
9. **Missing-file is NOT corruption** (D-16).     // ---- UTF-8 boundary (RESEARCH Recipe 4) ----

    std::string toUtf8(const std::wstring& w) {
    #ifdef _WIN32
        if (w.empty()) return {};
        int needed = WideCharToMultiByte(CP_UTF8, 0,
                                         w.data(), static_cast<int>(w.size()),
                                         nullptr, 0, nullptr, nullptr);
        if (needed <= 0) return {};
        std::string out(static_cast<size_t>(needed), '\0');
        WideCharToMultiByte(CP_UTF8, 0,
                            w.data(), static_cast<int>(w.size()),
                            out.data(), needed, nullptr, nullptr);
        return out;
    #else
        // Non-Windows: lossy ASCII fallback consistent with project's Windows-only milestone.
        std::string out;
        out.reserve(w.size());
        for (wchar_t c : w) {
            if (c < 128) out.push_back(static_cast<char>(c));
        }
        return out;
    #endif
    }

    // Returns false on invalid UTF-8 (MB_ERR_INVALID_CHARS); caller logs + uses default. (D-09)
    bool fromUtf8(const std::string& s, std::wstring& out) {
        out.clear();
        if (s.empty()) return true;
    #ifdef _WIN32
        int needed = MultiByteToWideChar(CP_UTF8, MB_ERR_INVALID_CHARS,
                                         s.data(), static_cast<int>(s.size()),
                                         nullptr, 0);
        if (needed <= 0) return false;
        out.resize(static_cast<size_t>(needed));
        int written = MultiByteToWideChar(CP_UTF8, MB_ERR_INVALID_CHARS,
                                          s.data(), static_cast<int>(s.size()),
                                          out.data(), needed);
        return written == needed;
    #else
        out.assign(s.begin(), s.end());
        return true;
    #endif

    // ---- Bounds validators (RESEARCH Recipes 3 + 7) ----

    template <typename T>
    T clampRange(T value, T lo, T hi, const char* name) {
        if (value < lo) {
            MICMAP_LOG_WARNING("Config '", name, "'=", value,
                               " out of range [", lo, ",", hi, "]; clamping to ", lo);
            return lo;
        }
        if (value > hi) {
            MICMAP_LOG_WARNING("Config '", name, "'=", value,
                               " out of range [", lo, ",", hi, "]; clamping to ", hi);
            return hi;
        }
        return value;
    }

    int snapPowerOfTwo(int value, int lo, int hi, const char* name) {
        int v = value < lo ? lo : (value > hi ? hi : value);
        if (v > 0 && (v & (v - 1)) == 0 && v == value && value >= lo && value <= hi) {
            return value;
        }
        int p = lo;
        int next = p * 2;
        while (next <= hi && next <= v) { p = next; next = p * 2; }
        int chosen;
        if (next > hi) {
            chosen = p;
        } else {
            chosen = (v - p <= next - v) ? p : next;
        }
        if (chosen != value) {
            MICMAP_LOG_WARNING("Config '", name, "'=", value,
                               " is not a power of 2 in [", lo, ",", hi,
                               "]; snapping to ", chosen);
        }
        return chosen;
    }

        }
    }

                fs::remove(tmp, remEc);
                return false;
            }
        }
        return true;
