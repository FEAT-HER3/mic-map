## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Retry thread → vrserver | Crosses process boundary via OpenVR shared-mem IPC. vrserver is trusted. Thread writes to OpenVR's per-user appconfig.json via API — no FS writes outside. |
| Retry thread ↔ main thread | Shared state: `manifestRetryCancel` (atomic, lock-free). `manifestRegistrar` ptr read-only after initialize(). |
| shutdown() ordering | Single-threaded execution; main loop has exited. No concurrent access to torn-down subsystems. Retry thread joined FIRST to prevent mid-VR_Init race. |
