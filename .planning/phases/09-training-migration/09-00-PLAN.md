## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| build-time → CI | Lint scripts run with FATAL_ERROR; bypass = code injection or scope drift in CLIENT_ROOTS / REPLAY_DIR args |
| test executable → host filesystem | Test scaffolds open temp files (some) and parse JSON; trust boundary is local dev/CI host |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-00-01 | Tampering | cmake/AssertNoClientTraining.cmake | mitigate | Hardcode `apps/mic_test` allowlist match in lint body (`if(_dir MATCHES "apps/mic_test") continue()`) so a future scope-drift attempt that pipes mic_test through CLIENT_ROOTS still cannot trip the violation pattern |
| T-09-00-02 | Tampering | cmake/AssertReplayNoVrApi.cmake | mitigate | Use explicit-target-list (not GLOB_RECURSE) — the 2 `_targets` paths are pinned in the lint source; cannot be silently broadened by an attacker editing build args |
| T-09-00-03 | Spoofing | tests/CMakeLists.txt EXISTS-gated source lists | accept | Local dev/CI trust boundary; if attacker can write `driver/src/training_session.cpp` they already have repo write access — separate concern |
| T-09-00-04 | DoS | RED-tolerant scaffolds at Wave 0 | accept | Scaffolds are designed to fail to build until impl ships; that IS the gate, not a DoS |
| T-09-00-05 | Information disclosure | tests scaffold MM_CHECK output | accept | stderr "FAIL: <expr> at line N" surfaces only file-line + expression text; no PII or secret material |
